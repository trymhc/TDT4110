# Uke 39: Lister, arrays og uttrykk

Denne uka arbeider vi videre med sekvenser og lister, med særlig vekt på hvordan data kan organiseres, endres og behandles i Python.

## Temaer

1. **Lister som sekvenser**
   - indekser og slicing
   - iterasjon med `for`
   - `range()` og indeksbaserte løkker

2. **Muterbarhet**
   - muterbare og ikke-muterbare objekter
   - referanser og aliasering
   - endring in-place kontra oppretting av nye objekter
   - kopiering av lister
   - lister av lister

3. **Listeoperasjoner**
   - `append()`, `extend()`, `insert()` og `remove()`
   - `sort()` kontra `sorted()`
   - returverdi og sideeffekt

4. **Listeforståelser**
   - lage nye lister fra løkker
   - filtrering med betingelser
   - tupler og generatoruttrykk

5. **If-uttrykk**
   - forskjellen mellom if-setninger og if-uttrykk
   - bruke betingelser til å beregne en verdi

6. **Pakking og utpakking**
   - pakke verdier i tupler
   - pakke ut verdier til variabler
   - bruke `*` og `**` ved funksjonskall
   - `*args` som samling av flere argumenter

## Anbefalt rekkefølge

Start med indeks og referanser, gå videre til muterbarhet og kopiering, og bruk deretter listeforståelser og if-uttrykk til å uttrykke beregninger mer kompakt.
